# Chux · 出行清单

手机 / 电脑端出行前携带物品与注意事项提醒小工具。

在线使用：打开 `index.html` 或部署后访问即可。

## 功能

- **实时天气**：输入目的地城市，显示当前温度、体感、湿度、风速及今明后三天预报（Open-Meteo，免费无 Key）
- **分类清单**（全部一页展示，无折叠）
  - 证件类：身份证、通行证、护照、驾驶证
  - 洗漱类：洗漱用品、防晒、发胶、洗面奶
  - 电器类：充电器、充电宝、耳机、剃须刀、手表、相机
  - 药物类：感冒药、肠胃药、清热解毒、高反药
  - 其他：口罩、雨伞、墨镜、眼罩、靠枕、纸巾、钥匙
  - 衣物类：根据天气准备衣物、换洗衣物等
- **进度追踪**：实时显示完成数量与百分比
- **本地存储**：勾选状态与上次查询城市自动保存
- **自定义添加**：可随时添加个人物品
- **出门前检查**：门窗水电、垃圾、票站时间等提示
- **响应式布局**：手机单列 / 电脑多列，一页看完

## 使用

1. 用浏览器直接打开 `index.html`
2. 或部署到 GitHub Pages / 任意静态托管
3. 建议「添加到主屏幕」获得接近 App 的体验

## 技术

纯 HTML + CSS + JS，零依赖。天气数据来自 [Open-Meteo](https://open-meteo.com/)。
